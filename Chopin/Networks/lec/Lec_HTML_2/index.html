ВАЖНОЕ ПРЕДУПРЕЖДЕНИЕ:
Ошибка в пропорциях превратит эликсир в яд!
Принимать строго по 3 капли.

Компоненты для сборки

  • Растительные ингредиенты
    • Корень мандрагоры
    • Цветок папоротника
      • Только ночной сбор
      • Только свежие лепестки
  • Минералы
    • Толченый лунный камень
    • Слеза дракона

Порядок приготовления

  1. Смешать ингредиенты в медной чаше.
  2. Варить на медленном огне ровно 40 минут.
  3. Остудить под светом полной луны.

Формула реакции:

H2O + Специи = Золото
