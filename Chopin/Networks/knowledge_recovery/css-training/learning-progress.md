## Блок 1 — связь HTML и CSS, атрибуты и селекторы

- Выполнено: упражнение с `class`, `id` и селектором тега на небольшой странице. HTML и CSS написаны самостоятельно; проверка по файлам пройдена.
- Изучено: HTML-атрибуты `class` и `id`, селекторы `p`, `.fact`, `#section-title`, подключение отдельного CSS-файла.
- Основные ошибки: сначала общий цвет абзацев был задан только классу; затем добавлено правило `p`. Цвет в `.fact` остался избыточным, но не меняет результат.
- Понято самостоятельно: почему селектор тега действует на все абзацы, селектор класса — только на отмеченные; почему после удаления повторного цвета из `.fact` текст останется тёмно-синим.
- Требует повторения: термин «селектор класса»; каскад и приоритет правил ещё не проверены.
- Выполнено по коду: группировка заголовков и правила для тега, класса и идентификатора. Предсказание цветов всех трёх абзацев не завершено; пользователь попросил идти дальше.
- Понято самостоятельно по второму упражнению: `#lead` имеет больший приоритет, чем `.note` и `p`; второй абзац тёмно-красный.
- Требует повторения: самостоятельное определение результата каскада для нескольких элементов.

## Блок 2 — блочная модель

- Выполнено частично: карточки оформлены самостоятельно; `box-sizing: border-box` после подсказки перенесён на нужный класс. На последней проверке рамка оставалась пунктирной вместо сплошной.
- Изучено: содержимое, `padding`, `border`, `margin`, `box-sizing`.
- Основные ошибки: сначала не был задан стиль рамки; `border-box` стоял у другой карточки; 36px для первой карточки были приняты за её полную ширину, хотя это лишь сумма внутренних отступов и рамок.
- Понято самостоятельно: для второй карточки с `width: 260px` и `border-box` содержимое занимает 224px.
- Требует повторения: полная ширина при обычном расчёте и влияние внешних отступов. Пользователь попросил перейти дальше до завершения расчёта.
- Выполнено: процентные размеры и центрирование вложенных блоков. После подсказки проценты поставлены на нужные элементы; HTML не менялся.
- Понято самостоятельно: `.panel` считает 50% от родителя `.page`; после разбора дерева HTML определён родитель `.page` — `body`.
- Основные ошибки: сначала 80% и 50% были назначены противоположным блокам.
- Требует повторения: полная ширина при обычной блочной модели и влияние внешних отступов. Процентные размеры можно закрепить на следующем макете.

## Блок 3 — типы отображения

- Выполнено: горизонтальное меню из трёх ссылок с `inline-block`, заданной шириной, внутренним отступом, фоном и центрированным текстом.
- Понято самостоятельно: `block` начинает новую строку, `inline` остаётся в строке без управляемой ширины, `inline-block` остаётся в строке и допускает заданную ширину.
- Основные ошибки: сначала не было `text-align: center`; `margin: auto` использовался без эффекта для центрирования текста.
- Требует повторения: перенос строчных и строчно-блочных элементов при нехватке места, пробелы между `inline-block`, вертикальное выравнивание.
- Текущее упражнение: ряд карточек с `vertical-align` — ожидает самостоятельного выполнения.
